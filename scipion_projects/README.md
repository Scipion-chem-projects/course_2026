# Scipion-chem projects
This folder contains the compressed Scipion-chem projects that has been used in the course. 
Once you download and decompress them, you can place the directories in the ScipionUserData/projects folder or iport them from the project manager to be able to open them in your local Scipion installation.

Some projects are too heavy to be stored in GitHub, so here you have a link where you can download them: https://saco.csic.es/s/YPLq6pXd4gaJf7X

*Notice that you will not be able to open nor run the protocols coming from plugins you have not yet installed in your Scipion environment.
